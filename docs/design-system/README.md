# portalshit.net の既存デザイン

この文書は公開サイト用テーマの現状を記録したもの。新しい規格や、全画面に適用するトークンの提案ではない。変更時は対象画面のテンプレートと SCSS を読み、カスケード、状態、画面幅、ライト・ダーク両モードを確認する。値は CSS の指定値であり、継承やブラウザ・フォント環境によって実際の表示は変わる。記載のない画面や状態は不明として、類似実装を調べても判断できなければユーザーに確認する。

調査日: 2026-11-22。対象は `public/theme/portalshit` と公開画面で使われる Archives・Activity Tracker の関連実装。管理画面 (`public/admin`) や他のテーマは別の実装であり、この文書をそのまま適用しない。公開トップと記事ページをデスクトップのライト・ダーク両モードで確認し、写真ヘッダー、ナビゲーション、本文領域、記事見出し、OGPカードを照合した。ダークモードでは Archives のヒートマップとフィルターも確認した。暗い半透明の本文領域から背景写真が透け、文字は明色、リンクは赤系で、OGPカードと Archives の入力欄は明色のまま表示される。確認した範囲では既存コードの記録と大きな相違は見られなかった。コントラスト比の測定や、すべての背景画像での可読性の評価は行っていない。全ページ、モバイル、操作状態や外部埋め込みは実画面で網羅していない。本番と作業ツリーの版が一致するかも未確認。以下の詳細はコードに基づく。

## 文書の構成

- [tokens.md](tokens.md): 既存の配色、文字、余白の指定。全画面共通の規格として定めたものではない。
- [components.md](components.md): ページ構造、画像、画面ごとのコンポーネント。
- [guidelines.md](guidelines.md): 変更時の参照と確認の進め方。
- [screenshots/](screenshots/): 今後、確認用の画像を保存する場所。現時点で画像は保存していない。
